# Grilli Restaurant

## Overview

Grilli Restaurant is a responsive restaurant landing page designed to showcase delicious menu items, chef expertise, and booking information. The website focuses on providing a clean, modern experience for restaurant visitors, highlighting menu categories, dining ambiance, and easy reservation contact details.

## Features

- Responsive hero section with promotional content
- Menu showcase with featured dishes and food categories
- Contact and booking call-to-action
- Restaurant location, opening hours, and reservation details
- Modern UI with smooth navigation and visual imagery

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Ionicons

## Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Open `Index.html` in a web browser.
4. Alternatively, deploy the project to GitHub Pages or any static hosting service.

## Usage

Use the navigation menu to explore the homepage sections, view featured menu items, and learn about the restaurant’s services. Click the contact or booking link to access reservation details, and scroll through the chef and testimonial sections for more information.
